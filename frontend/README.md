# 🚀 Project Name - Ecomerce

This is the frontend of a modern e-commerce website. It is built to provide users with a fast, smooth, and mobile-friendly online shopping experience.

## 🛠️ Tech Stack

* **Core:** React.js (Vite)
* **Styling:** Tailwind CSS / Styled Components
* **Data Fetching:** Axios
* **Routing:** React Router DOM

## 📁 Folder Structure

```text
src/
├── components/     # Reusable UI components (Buttons, Cards)
├── pages/          # Page views/screens
└── services/       # API call definitions (Axios instances)

```

## ⚙️ Installation & Setup

Follow these steps to get your local development environment running.

1. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   Create a `.env` file in the root of your frontend folder.
   ```env
   VITE_API_URL=
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

## 📜 Available Scripts

In the project directory, you can run:

* `npm run dev` - Runs the app in development mode.
* `npm run build` - Builds the app for production to the `dist` or `build` folder.
* `npm run preview` - Locally previews your production build.
